# Gowtham-Portfolio

This is a premium Cyber DevOps Portfolio built using Next.js, Tailwind CSS, and TypeScript.

## Features
- **Interactive Cyber Terminal**: A fully functional retro-styled terminal emulator.
- **Admin Dashboard**: Manage projects, skills, and settings.
- **Supabase Integration**: Real-time database and secure authentication.
- **AI Agent Chat**: Interactive chat powered by Google Gemini.
- **Modern UI/UX**: Futuristic dark mode aesthetic with glassmorphism and smooth animations.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
